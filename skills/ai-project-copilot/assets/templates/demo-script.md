## Timeline

### 0–8 seconds — Problem

Show the painful input or failure. Say one sentence.

### 8–20 seconds — Action

Start the realistic workflow. Point out permissions and local/cloud status only if material.

### 20–42 seconds — Wow moment

Reveal the unique transformation:

- What appears?
- What should the cursor/camera focus on?
- What must already be loaded?

### 42–52 seconds — Trust

Open one citation, trace, approval checkpoint, eval, model manifest, or local-only indicator.

### 52–60 seconds — Artifact

Export, apply, share, or continue from the result. End on the user outcome.
